# Knowledge Core

AIDA's knowledge is structured, versioned and source-aware.

## Sources

Supported source classes include:
- PDF
- DOC/DOCX
- XLS/XLSX
- catalogues
- product sheets
- price lists
- offers
- contracts/conditions
- FAQs
- procedures
- presentations
- authorized email/WhatsApp conversations
- connected folders/files
- direct business instructions

## Critical facts

Prices, discounts, availability, deadlines, contractual terms and policies require:
- source
- version
- effective date
- validity status
- tenant
- optional approval

If no authoritative source exists, AIDA must not invent the value.

## Retrieval

Knowledge retrieval should return evidence identifiers so downstream decisions can be audited. Sensitive content must respect tenant, role and document permissions.
