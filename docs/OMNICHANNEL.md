# Omnichannel

AIDA maintains one customer identity and one project timeline across authorized channels.

Target adapters:
- Email
- WhatsApp
- SMS
- Telegram
- Facebook Messenger
- Instagram messaging
- TikTok messaging
- Voice
- Calendar

## Message lifecycle

Receive → identify customer → resolve project → retrieve context → classify intent → retrieve knowledge → draft/act → policy check → send/hand off → log outcome.

Channel availability depends on official APIs, permissions, account type and provider capabilities. AIDA never bypasses platform restrictions.

## Handoff briefing

Before human takeover, create a concise briefing containing:
- customer
- project
- channel
- conversation summary
- objective
- quote/offer if relevant
- objection/problem
- actions already performed
- missing information
- recommended next action
